# Book & Quill

A small Minecraft-style note editor built with plain HTML, CSS, and JavaScript. Text flows across pages, the page arrows let you move through the book or open a page early, Ctrl+B toggles bold, Ctrl+I toggles italics, and notes save in this browser automatically.

## Run locally

Install Node.js, open a terminal in this folder, and run:

```sh
node serve.js
```

Then open [http://localhost:5600](http://localhost:5600).

The book artwork and Minecraft Regular, Bold, Italic, and Bold Italic fonts are in `assets/`.
